HOW TO USE:
-----------
1. LOCAL SCAN:
   $ python main.py scan
   → Fetches live data, ranks by squeeze score, saves to data/

2. BACKTEST:
   $ python main.py backtest
   → Simulates strategy on historical data

3. DASHBOARD:
   $ python main.py serve
   → Starts Flask server at http://localhost:5000

4. DEPLOY:
   $ ./deploy.sh
   → Pushes to GitHub + deploys to Tiiny

SQUEEZE SCORE FORMULA:
----------------------
  Score = (SI_Density × 0.40) + (Borrow_Pressure × 0.25)
        + (Liquidity_Trap × 0.20) + (Momentum_Fuel × 0.15)

  • SI_Density:     short_pct_float normalized 0-100
  • Borrow_Pressure: days_to_cover + float scarcity
  • Liquidity_Trap:  short_shares / avg_daily_volume
  • Momentum_Fuel:   price_compression + SI_increase

STRATEGY RULES:
---------------
  Entry:  squeeze_score ≥ 70  AND  volume > 1.5× 20-day avg
  Hold:   max 5 trading days
  TP:     +20%
  SL:     -10%

DATA SOURCES:
